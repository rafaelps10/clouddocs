# CloudDocs

Plataforma de gerenciamento de documentos construída com Node.js, React e AWS.

## Objetivo

O CloudDocs permite que usuários façam upload, armazenamento, consulta, download e exclusão de documentos.

## Tecnologias

- Node.js
- Express
- React
- PostgreSQL
- Amazon S3
- Amazon RDS
- AWS IAM
- Amazon CloudWatch
- GitHub Actions

## Arquitetura

O projeto será desenvolvido inicialmente em ambiente local e posteriormente integrado à AWS.
